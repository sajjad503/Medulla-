## 🌟 ۱. نسخه اصلی و فعال: PHP + MySQL + React (توصیه‌شده)

این نسخه، نگارش نهایی و پایدار برای محیط‌های عملیاتی (Production) و استقرار روی **هاست‌های اشتراکی ارزان‌قیمت (cPanel / DirectAdmin / Apache / LiteSpeed)** یا سرورهای ابری است. از این پس، تمامی قابلیت‌های جدید فقط روی این نسخه اعمال می‌گردد.

### مزایای کلیدی نسخه PHP:
- **نیاز به سرور گران‌قیمت ندارد**: روی ساده‌ترین و ارزان‌ترین هاست‌های لینوکسی اشتراکی بدون نیاز به Node یا Python به بهترین شکل اجرا می‌شود.
- **معماری بدون فریم‌ورک سنگین (Vanilla PHP 8+)**: بیشترین بازدهی، سرعت لود زیر ۵۰ میلی‌ثانیه و بدون مصرف بی‌رویه رم.
- **پایگاه‌داده قدرتمند MySQL / MariaDB**: ذخیره‌سازی دائمی و امن اطلاعات در جداول نرمالایز شده با فایل آماده `medulla.sql`.
- **ارتباط کامل بین پنل‌ها**:
  - مشاور به اولیا پیام می‌دهد و در لحظه در پنل اولیا ظاهر می‌شود.
  - اولیا برنامه هفتگی را مشاهده و جدول را چاپ می‌کنند.
  - ثبت درخواست تماس تلفنی اولیا در تقویم مشاور.
  - برنامه‌ریز روزانه ۲۴ ساعته با قابلیت ثبت نمره و بررسی مشاور.
  - مدیریت کل، فعال/مسدودسازی مشاوران و موسسات.

### نحوه استقرار نسخه PHP در cPanel:
1. دیتابیس را در cPanel ایجاد کنید و فایل `medulla.sql` را در **phpMyAdmin** ایمپورت کنید.
2. مشخصات دیتابیس را در فایل `api/db.php` وارد نمایید.
3. دستور `npm run build` را اجرا کرده و خروجی پوشه `dist` را به همراه پوشه `api/` و فایل `.htaccess` داخل پوشه `public_html` هاست آپلود کنید.
*(راهنمای گام‌به‌گام تصویری در فایل `CPANEL_DEPLOYMENT_GUIDE.md` موجود است).*

## 🛠 ابزارهای بسته‌بندی مستقل (Export to ZIP)
برای راحتی شما در آپلود در گیت‌هاب و دانلود جداگانه هر نسخه، دو اسکریپت آماده ایجاد شده است:
- جهت ساخت فایل زیپ اختصاصی نسخه PHP: اجرای دستور `npm run zip:php`
- جهت ساخت فایل زیپ اختصاصی نسخه پایتون: اجرای دستور `npm run zip:python`
