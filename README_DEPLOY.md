## ۲. روش راه‌اندازی روی سرور لینوکس / اوبونتو / سرور شخصی (VPS / Ubuntu)

### پیش‌نیازها:
- Node.js نسخه 18 یا بالاتر (پیشنهاد: Node.js 20 یا 22)
- npm یا yarn یا pnpm

### مراحل اجرا:
```bash
# ۱. استخراج فایل فشرده
unzip medulla-source.zip
cd medulla-app

# ۲. نصب وابستگی‌ها
npm install

# ۳. اجرای بیلد نهایی کلاینت
npm run build

# ۴. اجرای سرور (شامل بک‌اند Express و فرانت‌اند بهینه‌شده)
npm run start
```
سرور به صورت پیش‌فرض روی پورت **3000** بالا خواهد آمد (`http://YOUR_SERVER_IP:3000`).

---

## ۳. اجرای مداوم در پس‌زمینه با PM2 (پیشنهادی برای سرور تولیدی)
```bash
npm install -g pm2
pm2 start server.ts --name medulla --interpreter tsx
pm2 save
pm2 startup
```

---

## ۴. اجرای با داکر (Docker) - اختیاری
یک فایل `Dockerfile` با محتوای زیر در روت پروژه قرار دهید:
```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build
EXPOSE 3000
CMD ["npm", "run", "start"]
```
سپس اجرا کنید:
```bash
docker build -t medulla .
docker run -d -p 3000:3000 --name medulla-app medulla
```
