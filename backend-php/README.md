# بک‌اند فعال و اصلی پلتفرم مدولا (PHP Vanilla + MySQL PDO)
## Medulla Platform - Active PHP Edition

> 🚀 **نسخه اصلی، پایدار و فعال (Production Ready)**
> این نسخه هسته فعال و در حال توسعه سیستم مشاوره تحصیلی «مدولا» است که برای تمامی محیط‌های هاست اشتراکی (cPanel / DirectAdmin / Apache / LiteSpeed) و سرورهای ابری (لیارا و ...) طراحی شده است.

---

### ویژگی‌های کلیدی این نسخه:
- **عدم وابستگی به فریم‌ورک‌های سنگین**: استفاده از Vanilla PHP 8+ با حداکثر سرعت لود و کمترین مصرف رم.
- **امنیت کامل دیتابیس**: پیاده‌سازی معماری امن با PDO و Prepared Statements برای پیشگیری ۱۰۰٪ از آسیب‌پذیری‌های SQL Injection.
- **احراز هویت استاندارد JWT**: امضا و اعتبارسنجی توکن‌های امنیتی ۷ روزه برای تمامی نقش‌ها.
- **سازگاری کامل با فرانت‌اند React SPA**: مدیریت تمامی هدرهای CORS و روت‌های مربوط به برنامه‌ریزی، گزارش‌کار، آزمون‌ها، نظارت اولیا و مدیر ارشد.

### فایل‌های این بخش:
| فایل | وظیفه |
| :--- | :--- |
| `db.php` | پیکربندی دیتابیس MySQL، اتصال PDO و توابع کمکی JWT |
| `index.php` | روتر مرکزی جهت پاسخ‌گویی به کلیه درخواست‌های API |
| `login.php` | احراز هویت تمامی کاربران (مدیر، مشاور، دانش‌آموز، اولیا) |
| `founder_dashboard.php` | آمار جامع پلتفرم، کنترل مالی و مدیریت اعضا توسط مدیر ارشد |
| `study_plans.php` | دریافت و ویرایش برنامه‌ریزی هفتگی مطالعه |
| `reports.php` | ارسال گزارش‌های کار روزانه دانش‌آموزان و ثبت نظر مشاور |
| `daily_planner.php` | مدیریت جدول زمانی ۲۴ ساعته روزانه در ۶ دسته‌بندی |
| `messages.php` | سیستم پیام‌رسانی دوطرفه مشاور با اولیا |
| `parent_dashboard.php` | کارنامه تجمیعی فرزند و ثبت درخواست تماس اولیا با مشاور |
| `subscription.php` | مدیریت امور مالی، تایید فیش‌ها و شهریه دانش‌آموزان |
| `medulla.sql` | اسکریپت ساخت پایگاه داده MySQL و داده‌های اولیه تست |
